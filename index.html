Flujo de cambios con técnicas de ramas

GitFlow

Las features salen de develop, se integran a develop y luego se libera a main.

feacture01→ develop→ main
feacture02→ develop
feacture03→ develop 
git merge --no-ff feacture01
git merge --no-ff feacture02
git merge --no-ff feacture03

Trunk-Based Development

Ramas cortas que se integran directo al tronco main. Lo incompleto no se integra.

feature-a→main
feature-b→main
feature-c✗sin integrar
